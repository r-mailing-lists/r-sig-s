# r-sig-s

Compatibility between R and S

Automated mbox archive. Updated daily via GitHub Actions.

## Structure

- `raw/` - Monthly .mbox files downloaded from [https://stat.ethz.ch/pipermail/r-sig-s/](https://stat.ethz.ch/pipermail/r-sig-s/)
- `processed/` - Structured JSON output from rmail-parser
- `meta.json` - List statistics

## Viewer

This list is not shown on [r-mailing-lists.thecoatlessprofessor.com](https://r-mailing-lists.thecoatlessprofessor.com/): apart from nine messages from 2001, its archive holds only spam.
